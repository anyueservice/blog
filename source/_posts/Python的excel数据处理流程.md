# 半亩PY.xlsx 数据处理流程文档

## 概述

对 `半亩PY.xlsx` 文件进行三步自动化处理，涉及两个 sheet：
- **半亩**：主表，需要写入结果
- **1-4月生产领料**：数据来源表

所有脚本均**不修改原文件**，处理结果输出到 `D:\备用\Python代码\Excel操作\Excel_out\半亩PY.xlsx`。

---

## 执行顺序

```
第1步：累计数量.py  →  第2步：填写是否料体.py  →  第3步：匹配批号.py
```

> **重要**：必须按顺序执行，因为后续脚本依赖前一步的输出结果。

---

## 第1步：累计数量

**脚本**：`累计数量.py`

### 功能

将"1-4月生产领料"表中相同"生产订单+行号+子件编码"的记录进行汇总：

| 来源表字段 | 操作 | 写入主表字段 |
|---|---|---|
| 申请数量 | 按关键字累计求和 | 对应半成品计划量 |
| 实发数量 | 按关键字累计求和 | 对应半成品完工量 |

### 匹配逻辑

- 主表"生产订单+行号+子件编码" 与 来源表"生产订单+行号+子件编码" 一一对应
- 同一个关键字在来源表中可能有多条记录，将申请数量和实发数量分别累加
- 非数值自动跳过，不参与累加

### 列定位方式

自动扫描表头行定位列位置，无需手动配置列字母。

### 输出示例

```
  第2行 | 关键字: MO20240001+10+A001 | 累计申请: 100, 累计实发: 98
  第3行 | 关键字: MO20240001+20+B002 | 累计申请: 50, 累计实发: 50

===== 处理统计 =====
主表总行数（不含表头）：500
匹配成功的行数：320
未匹配的行数：180
```

---

## 第2步：填写是否料体

**脚本**：`填写是否料体.py`

### 功能

根据第1步写入的"对应半成品计划量"列的值，判断并填写"是否料体"列：

| 对应半成品计划量的值 | 是否料体填入 |
|---|---|
| 有数值 | 是 |
| 空 | 否 |
| #N/A | 否 |

### 列配置

| 列 | 表头名 | 作用 |
|---|---|---|
| S列 | 对应半成品计划量 | 判断依据（第1步写入的结果） |
| P列 | 是否料体 | 填写目标 |

### 输出示例

```
===== 处理统计 =====
总处理行数：500
填入'是'的行数：320
填入'否'的行数：180
```

---

## 第3步：匹配批号

**脚本**：匹配批号.py

### 功能

仅对"是否料体"为"是"的行，从"1-4月生产领料"表匹配批号并写入：

- 1个批号 → 写入 R列（对应领料批号1）
- 多个批号 → 依次写入后续列（对应领料批号2、3...）
- 批号自动去重
- 列不足时自动插入新列，原有列右移不覆盖

### 列配置

| 列 | 表头名 | 作用 |
|---|---|---|
| P列 | 是否料体 | 过滤条件（仅"是"才处理，第2步写入的结果） |
| Q列 | 生产订单+行号+子件编码 | 匹配关键字 |
| R列起 | 对应领料批号1、2、3... | 写入批号 |

### 匹配逻辑

1. 先检查 P列"是否料体"，仅值为"是"的行才处理
2. 用 Q列"生产订单+行号+子件编码"与来源表 E列匹配
3. 查出来源表 I列"批号"，去重后排序
4. 批号数量超过现有列数时，自动插入新列（原有数据右移）

### 输出示例

```
  第2行 | 关键字: MO20240001+10+A001 | 匹配到 3 个批号: PH001, PH002, PH003

===== 处理统计 =====
主表总行数（不含表头）：500
因'是否料体'不为'是'而跳过的行数：180
匹配到批号的行数：310
每行最多对应不同批号数：5
批号列总数：5（原有 1，新增插入 4）
```

## 整体数据流

```
┌─────────────────────────────────────────────────────────────────┐
│                    原始 Excel 文件                               │
│  ┌──────────────┐          ┌──────────────────┐                │
│  │   半亩 sheet  │          │ 1-4月生产领料 sheet│                │
│  │              │          │                  │                │
│  │ P: 是否料体   │          │ E: 生产订单+行号   │                │
│  │ Q: 生产订单   │          │    +子件编码      │                │
│  │ R: 对应领料批号│          │ I: 批号          │                │
│  │ S: 对应半成品  │          │ 申请数量          │                │
│  │    计划量     │          │ 实发数量          │                │
│  │ T: 对应半成品  │          │                  │                │
│  │    完工量     │          │                  │                │
│  └──────────────┘          └──────────────────┘                │
└─────────────────────────────────────────────────────────────────┘

第1步：累计数量.py
  来源表(申请数量) ──累计求和──→ 主表(S: 对应半成品计划量)
  来源表(实发数量) ──累计求和──→ 主表(T: 对应半成品完工量)

第2步：填写是否料体.py
  主表(S: 对应半成品计划量) ──有数值?──→ 主表(P: 是否料体 = "是"/"否")

第3步：匹配批号.py
  主表(P: 是否料体) ──仅"是"──→ 过滤行
  来源表(E→I: 批号) ──匹配──→ 主表(R起: 对应领料批号1, 2, 3...)
```

---

## 注意事项

1. **执行顺序**：必须按 1→2→3 顺序执行，每步的输出文件是下一步的输入
2. **文件占用**：运行脚本前请关闭 Excel 文件，避免文件被占用导致保存失败
3. **依赖库**：需要安装 `openpyxl`，安装命令：`conda install openpyxl` 或 `pip install openpyxl`
4. **输出文件**：所有结果保存在 `D:\备用\Python代码\Excel操作\Excel_out\` 目录下
5. **重复执行**：如需重新运行，建议从第1步开始，确保数据一致性
